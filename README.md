# hello-python
My first Python project: greets the user and prints their
name as an ASCII banner (using the open-source pyfiglet library).
It also includes expressions.py, exploring Python expressions,
operators, and Boolean logic. An accompanying Jupyter notebook,
explore.ipynb, repeats the experiments interactively.

Lab 1 - Fundamentals of Computer Programming,
BSc Data Science for Responsible Business.

## Reflection 
Virtual environments and requirements.txt help make a project reproductible because they keep its dependencies organized and documented. A virtual environment isolates the packages used by one project, while requirements.txt records the packages needed to rebuild it. Reproducibility matters in responsible data science because other people should be able to recreate and verify our work.
